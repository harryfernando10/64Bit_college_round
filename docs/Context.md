## Phase 3 Evidence Stress Lab

Added `POST /api/stress-experiment` and a frontend section for request-scoped source/passage removal and passage edits. The endpoint receives the validated baseline response, copies its source documents, validates selected source and retrieved passage IDs, and calls the regular audit service with the original answer and modified context. It never writes fixture files. Fixture baselines are labeled not directly comparable with perturbed engine results; the all-context-removed case returns a successful not-comparable result without attempting an invalid empty-source audit. See API_CONTRACT.md, ARCHITECTURE.md, and TEST_PLAN.md.

## Phase 5A credibility foundation

Added a transparent claim-triage layer for obvious questions, instructions, short unpunctuated headings/labels, and explicit first-person opinions. All spans and Unicode offsets remain in the response; `NOT_ASSESSED` has a separate count and can be overridden by claim ID. Added request-order `S1…` source labels while retaining source IDs for traceability, plus plain-language summaries and technical-detail disclosures in the UI. The Evidence Stress Lab walkthrough now documents a two-source custom baseline so removing one source leaves another in context; curated fixture results are called out separately.

Real NLI inference ran locally with the optional CPU stack installed into the ignored `.venv` and the pinned 568 MB checkpoint cached under ignored `models/refutella-nli`. Model load took about 17 seconds; warm single-pair inference took about 0.08–0.29 seconds on this machine. The smoke set returned entailment, contradiction, neutral, and entailment for a simple paraphrase. A different paraphrase probe (“four weeks” / “one month”) was incorrectly labeled contradiction, demonstrating fallibility. RAM was not measured. Raw logits remain uncalibrated, not probabilities of truth. The optional adapter remains off unless explicitly configured; backend regression tests also check the unconfigured and missing-weight fallback.
